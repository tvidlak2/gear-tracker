Privacy Policy

GearTracker respektuje tvoje soukromí. Tvá data zůstávají v tvém telefonu.

📅 Platnost od: dubna 2026
Zkráceně: GearTracker neposílá žádná tvá data na naše servery. Vše je uloženo pouze lokálně v telefonu. Jedinou výjimkou je volitelné propojení se Stravou, které probíhá přímo mezi tebou a Stravou.

1. Kdo provozuje tuto aplikaci

Aplikaci GearTracker vyvíjí a provozuje:
Tomas Vidlak

2. Jaká data aplikace zpracovává

GearTracker ukládá tato data výhradně lokálně na tvém zařízení (SQLite databáze):

  • Informace o vybavení (název, kategorie, datum koupě, fotografie)
  • Pravidla a záznamy údržby
  • Záznamy aktivit (trvání, vzdálenost, nastoupané metry, datum)
  • Nastavení aplikace (jazyk, notifikace, Strava konfigurace)
✅ Žádný cloud ✅ Žádná registrace ✅ Žádná analytika

3. Cloudové účty a servery

GearTracker nemá vlastní server ani backend. Nevytváříme žádné uživatelské účty a nepřijímáme žádná data z tvého telefonu.

Data aplikace nejsou nikdy odesílána třetím stranám za účelem reklamy, profilování ani prodeje.

4. Integrace se Stravou (volitelná)

Pokud se rozhodneš propojit GearTracker se Stravou, platí následující:

  • Autorizace probíhá přímo přes OAuth2 rozhraní Stravy — my nikdy nevidíme tvé přihlašovací údaje ke Stravě.
  • Přístupový token Stravy je uložen bezpečně na tvém zařízení (Android Keystore přes flutter_secure_storage).
  • Token je použit pouze pro stažení tvých aktivit ze Strava API přímo do telefonu.
  • Kdykoli můžeš Stravu odpojit v Nastavení → Propojené služby → Odpojit.

Strava má vlastní Privacy Policy dostupnou na strava.com/legal/privacy.

5. Oprávnění aplikace

  • Internet — pro komunikaci se Strava API (pouze pokud propojíš Stravu)
  • Notifikace — pro připomínky servisu (pouze pokud povolíš)
  • Čtení médií / fotoaparát — pro přidání fotografie vybavení (pouze pokud přidáš foto)
  • Čtení souborů — pro import IGC souborů (pouze při importu)

6. Jak smazat svá data

Všechna data jsou uložena lokálně. Můžeš je smazat dvěma způsoby:

  • Selektivně: Nastavení → Záloha a export → Vymazat všechna data
  • Kompletně: Odinstalací aplikace z telefonu

7. Děti

Aplikace není určena pro děti mladší 13 let a vědomě neshromažďujeme data od takových uživatelů.

8. Změny tohoto dokumentu

Pokud dojde k podstatným změnám v tom, jak nakládáme s daty, aktualizujeme datum platnosti tohoto dokumentu a (je-li to možné) upozorníme tě v aplikaci.
